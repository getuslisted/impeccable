Six patterns every reviewer misses.

Each one observable. Each one catchable.

Slop

AI code reads as AI code.

The same gradient on dark, the same three feature cards, the same "Empower your team" headline. Training-data reflexes.

Drift

Design systems drift faster than maintained.

One developer adds #f5f5f5. By month six there are dozens of near-identical grays.

A11y

WCAG audits surface too late.

The consultant arrives two weeks before launch. Contrast violations across thirty components.

Noise

Security scanners drown signal.

Static analysis reports hundreds of theoretical issues. Real attack paths get buried.

Review

PR review misses architectural drift.

Reviewers approve the diff but never check whether the new component reimplements a primitive.

Copy

Em dashes mark prose as machine.

The single most common signal of AI-written prose. So is delve, seamless, robust, pivotal.

Frequently asked.

Is it really free?

Yes. MIT licensed. No paid tier. No telemetry.

Does it require Claude Code?

The deterministic gate requires no AI tools.

What's the CI cost?

Under a second for the script. About 30 seconds with ripgrep install.

What languages?

CSS, HTML, JSX, TSX, Vue, Svelte, Markdown.

How to add rules?

Edit quality-checks/scripts/check.sh.

Will it break my build?

If your codebase has P0/P1 findings, yes. Use .qcignore for grandfathered content.

Configure homepage sections?

Edit _data/homepage.json or use /admin/.
